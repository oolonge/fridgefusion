Структура проекта

FridgeFusion — это приложение для поиска рецептов по доступным ингредиентам.

Компоненты:

  • REST API — backend на C++ с Crow framework
  • Desktop App — Qt 6 приложение
  • CLI — консольный интерфейс
  • Web Server — Caddy для маршрутизации
