# Лабы по ППО 2026 

## 1. Название проекта
FridgeFusion - система подбора рецептов на основе имеющихся ингредиентов и управления домашними запасами продуктов

## 2. Краткое описание идеи проекта
Веб-платформа, которая помогает пользователям разнообразить рацион, предлагая персонализированные рецепты на основе продуктов, имеющихся у них дома. Система также позволяет отслеживать запасы продуктов, их сроки годности и формировать списки покупок недостающих ингредиентов. 

## 3. Краткое описание предметной области
Предметной областью проекта является кулинария: рецепты и продукты, из которых они готовятся. Пользователь должен иметь возможность вести учет продуктов у себя дома: количество, калорийность и их сроки годности. Ориентируясь на них, программа должна будет предлагать рецепты из кухни на выбор, следуя которым можно приготовить интересеные блюда. 

## 4. Краткий анализ аналогичных решений по минимум 3 критериям

| Критерий | Tasty | Supercook | Mealime | FridgeFusion |
|----------|-------|-----------|---------|--------------|
| Предложение рецептов по имеющимся ингредиентам | Частично (не основной функционал) | Да (основная функция) | Нет (фокус на планировании) | Да (с учетом диеты и оборудования) |
| Учет кухонного оборудования | Нет | Нет | Нет | Да |
| Учет и отслеживание запасов продуктов | Нет | Нет | Частично | Да (с отслеживанием сроков годности) |

## 5. Краткое обоснование целесообразности и актуальности проекта
FridgeFusion решает распространенную проблему "полный холодильник, но нечего готовить", предлагая идеи блюд на основе имеющихся продуктов и учитывая диету пользователя. Проект актуален в условиях стремления к рациональному потреблению, минимизации пищевых отходов и оптимизации бюджета. Особую ценность представляет для людей, стремящихся эффективно управлять запасами продуктов.

## 6. Краткое описание акторов
1. Незарегистрированный пользователь (Гость) - имеет ограниченный доступ к каталогу рецептов и базовому поиску.
2. Зарегистрированный пользователь - может указывать имеющиеся ингредиенты, получать персонализированные рекомендации, управлять своим "виртуальным холодильником", сохранять любимые рецепты, оставлять отзывы и оценки, формировать списки покупок.
3. Контент-менеджер* - модерирует пользовательский контент, добавляет и редактирует рецепты в базе данных, категоризирует ингредиенты и рецепты.
4. Администратор системы - имеет полный доступ к функционалу платформы, управляет пользователями, настраивает параметры системы, анализирует статистику использования.

## 9. Пользовательские сценарии

Сценарий 1: Поиск рецепта по имеющимся ингредиентам (авториз/не авториз. пользователь)

- Пользователь авторизуется в системе FridgeFusion
- Переходит на страницу "Рецепты"
- Выбирает максимальное время приготовления 30 минут
- Нажимает кнопку "Найти рецепты"
- Система анализирует введенные данные и предпочтения пользователя
- Отображает список подходящих рецептов, ранжированных по релевантности
- Пользователь просматривает несколько рецептов и выбирает "Паста с овощами"
- Просматривает детальную информацию: список ингредиентов, время приготовления, шаги, фото
- После приготовления пользователь оценивает рецепт и оставляет комментарий (авториз.)
- Система обновляет предпочтения пользователя на основе его оценки (авториз.)

Сценарий 2: Добавление рецепта в избранное (авториз. пользователь)

- Пользователь авторизуется в системе FridgeFusion
- Переходит на страницу "Рецепты"
- Выбирает категорию или ингредиенты рецептов, которые его интересуют 
- Нажимает кнопку "Найти рецепты"
- Система анализирует введенные данные 
- Отображается список подходящих рецептов, ранжированных по релевантности
- Пользователь просматривает несколько рецептов и выбирает "Паста с овощами"
- Пользователю нравится рецепт и он хочет его сохранить - нажимает кнопку "В избранное"
- Теперь пользователь может найти этот рецепт у себя в профиле, в разделе "избранное"
- Также этот рецепт может быть удален из избранного, как на странице рецепта, так и в 
профиле, в соответствующей вкладке. 

Сценарий 3: Добавление собственного рецепта (только администратор)

- Пользователь переходит в раздел "Мои рецепты"
- Выбирает опцию "Добавить рецепт"
- Заполняет форму с основной информацией: название, описание, время приготовления
- Добавляет ингредиенты из выпадающего списка с указанием количества и единиц измерения
- Описывает пошаговые инструкции приготовления
- Указывает необходимое кухонное оборудование
- Выбирает категории, к которым относится рецепт
- Утверждает рецепт, который становится доступным для других пользователей
