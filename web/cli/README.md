# FridgeFusion CLI

Консольный интерфейс для работы с FridgeFusion REST API.

## Описание

CLI приложение для взаимодействия с системой управления рецептами FridgeFusion. Предоставляет интерактивный текстовый интерфейс для:

- Авторизации и регистрации пользователей
- Просмотра рецептов
- Поиска рецептов по ингредиентам и категориям
- Управления избранными рецептами
- Просмотра профиля пользователя
- Просмотра отзывов на рецепты

## Требования

### Системные зависимости

- C++17 или новее
- CMake 3.15+
- libcurl
- nlohmann_json 3.2.0+

### Установка зависимостей

**macOS (Homebrew):**
```bash
brew install curl nlohmann-json
```

**Ubuntu/Debian:**
```bash
sudo apt-get install libcurl4-openssl-dev nlohmann-json3-dev
```

**Fedora:**
```bash
sudo dnf install libcurl-devel json-devel
```

### REST API

CLI работает как HTTP-клиент и требует запущенного REST API сервера FridgeFusion.

По умолчанию подключается к: `http://localhost:8080/api/v2`

## Сборка

```bash
cd cli
mkdir build
cd build
cmake ..
make
```

После успешной сборки исполняемый файл `ff` будет создан в директории `build/`.

## Запуск

```bash
./ff
```

### Опции командной строки

- `--verbose` - Включить подробный вывод ошибок (отображает HTTP коды и полные тела ответов)

Пример:
```bash
./ff --verbose
```

## Конфигурация

Файл конфигурации автоматически создается при первом запуске:
```
~/.config/fridgefusion/cli.json
```

### Структура конфигурационного файла

```json
{
  "api_url": "http://localhost:8080/api/v2",
  "token": "",
  "user_id": -1,
  "verbose": false
}
```

- `api_url` - URL REST API сервера
- `token` - JWT токен для авторизованных запросов (заполняется автоматически)
- `user_id` - ID текущего пользователя (заполняется автоматически)
- `verbose` - Режим подробного вывода ошибок

## Использование

### Меню авторизации

При запуске без сохраненного токена отображается меню авторизации:

```
=== АВТОРИЗАЦИЯ ===
1. Войти
2. Зарегистрироваться
3. Выйти из программы
```

### Главное меню

После успешной авторизации доступно главное меню:

```
=== ГЛАВНОЕ МЕНЮ ===
1. Просмотр рецептов
2. Поиск рецептов по ингредиентам
3. Поиск рецептов по категории
4. Мой профиль
5. Избранные рецепты
6. Выйти из аккаунта
7. Выйти из программы
```

### Просмотр рецептов

Отображает список доступных рецептов с возможностью просмотра деталей по ID.

### Поиск рецептов

**По ингредиентам:**
1. Отображается список всех ингредиентов
2. Выберите ID ингредиентов для поиска (можно выбрать несколько)
3. Введите 0 для завершения выбора
4. Отображаются найденные рецепты

**По категории:**
1. Отображается список категорий
2. Выберите ID категории
3. Отображаются рецепты из выбранной категории

### Детали рецепта

При просмотре деталей рецепта отображается:
- Название и описание
- Время подготовки и приготовления
- Список ингредиентов с количеством
- Пошаговая инструкция
- Рейтинг и количество отзывов
- Отзывы пользователей

Доступные действия (для авторизованных пользователей):
- Добавить/удалить из избранного
- Вернуться назад

### Профиль пользователя

Отображает информацию о текущем пользователе:
- Имя пользователя
- Email
- Количество избранных рецептов
- Количество отзывов
- Количество созданных рецептов

## Архитектура

### Компоненты

- **HttpClient** - HTTP-клиент на базе libcurl для взаимодействия с REST API
- **ConfigManager** - Управление конфигурацией (JSON файл)
- **ConsoleView** - Форматированный вывод и ввод данных
- **AuthHandler** - Обработка авторизации и регистрации
- **RecipeHandler** - Работа с рецептами, ингредиентами, категориями
- **FavoriteHandler** - Управление избранными рецептами
- **UserHandler** - Работа с профилем пользователя
- **CLIApp** - Главный класс приложения, управление меню и логикой

## Обработка ошибок

### Обычный режим
Отображаются только сообщения об ошибках из API:
```
ОШИБКА: Invalid credentials
```

### Verbose режим
Отображаются подробные данные:
```
ОШИБКА: HTTP 401: {"error":"UNAUTHORIZED","message":"Invalid credentials"}
```

## Устранение неполадок

### Ошибка "Failed to initialize CURL"
Убедитесь, что libcurl установлен и доступен:
```bash
curl-config --version
```

### Ошибка "Ошибка соединения с сервером"
1. Проверьте, что REST API сервер запущен
2. Проверьте URL в конфигурационном файле
3. Убедитесь, что сервер доступен: `curl http://localhost:8080/api/v2/categories`

### Проблемы с конфигурацией
Удалите конфигурационный файл и перезапустите приложение:
```bash
rm ~/.config/fridgefusion/cli.json
./ff
```
